# SEO.md

## SEO Philosophy

This project is SEO-first.

SEO will not be added after the website is finished.  
SEO must be included in page structure, content, metadata, internal links, images, performance and schema from the beginning.

The goal is not to create many low-quality pages.

The goal is to create fewer but stronger pages that genuinely answer what customers search for.

## MVP Page Strategy

Create these pages first:

- Home
- Phone Repair
- Computer Repair
- Camera Systems
- Satellite Systems
- Electrical and Internet Services
- Products
- About
- Contact

Do not create separate pages for every district at the beginning.

Reason:

Too many similar district pages can become thin or duplicate content.

Better approach:

- Mention service areas naturally.
- Build strong service pages.
- Collect Search Console data.
- Later create district pages only if there is real search demand.

## Technical SEO Rules

Every page must have:

- One H1
- Clear H2/H3 structure
- Unique title
- Unique meta description
- Canonical URL
- Open Graph title and description
- Semantic HTML
- Optimized images
- Descriptive alt text
- Mobile-friendly layout
- Internal links
- Clear CTA
- Fast loading

Required files:

- sitemap.xml
- robots.txt

Use next-sitemap if needed.

---

## Schema Strategy

Use structured data where appropriate.

Required schema types:

### LocalBusiness

Use on homepage and contact page.

Include:

- Business name
- Address
- Phone
- Opening hours when confirmed
- Service area
- URL
- SameAs links if available
- Geo if coordinates are available later

### Organization

Use for general business identity.

### Service

Use on service pages.

Service pages:

- Phone Repair
- Computer Repair
- Camera Systems
- Satellite Systems
- Electrical and Internet Services

### FAQPage

Use where FAQ section exists.

### BreadcrumbList

Use on service and contact pages.

## Content Rules

Content must be helpful.

Each service page should include:

1. What the service is
2. Common problems
3. How the process works
4. Why choose Kılınç Teknomarket
5. Service area
6. FAQ
7. WhatsApp CTA

Avoid:

- Keyword stuffing
- Fake claims
- Duplicate content
- Long meaningless paragraphs
- AI-like generic text
- Creating pages only for SEO without real value

---

## Internal Linking Rules

Homepage should link to all main service pages.

Each service page should link to:

- Contact page
- Related services
- WhatsApp CTA

Example:

Phone Repair page can link to:

- Computer Repair
- Products
- Contact

Camera Systems page can link to:

- Electrical and Internet Services
- Contact
- WhatsApp CTA

---

## Image SEO Rules

Use real business photos when possible.

Rules:

- Use descriptive file names.
- Use alt text.
- Prefer WebP.
- Compress large images.
- Avoid heavy image sliders.
- Avoid layout shift.
- Do not use too many stock images.

Example alt text:

“Kılınç Teknomarket Beyoğlu mağaza dış cephe”

“Kılınç Teknomarket telefon kılıfı ve aksesuar ürünleri”

“Kamera sistemi kurulumu hizmeti”

## Google Review Strategy

The business owner said customers often cannot find where to leave a review.

Solution:

Create a Google review system.

Needed assets:

- Direct Google review link
- QR code
- Printable review card
- WhatsApp ready message

Message example:

“Merhaba, Kılınç Teknomarket olarak hizmetimizden memnun kaldıysanız aşağıdaki bağlantıdan bize Google yorumu bırakabilir misiniz? Desteğiniz bizim için çok değerli.”

Website should include:

- “Google’da yorum bırak” CTA
- Footer review link
- Contact page review link

## Performance SEO

Performance affects SEO and conversions.

Targets:

- Lighthouse SEO: 95+
- Lighthouse Performance: 90+
- Good Core Web Vitals
- Fast mobile load
- Optimized images
- Minimal JavaScript
- No heavy animations
- No unnecessary third-party scripts

---

## SEO Definition of Done

A page is SEO-ready only if:

- It has one H1
- It has unique metadata
- It has semantic HTML
- It has internal links
- It has CTA
- It has relevant schema if needed
- It has optimized images
- It works well on mobile
- It loads fast
- It provides real user value
